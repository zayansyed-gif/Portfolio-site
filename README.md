# Zayan Syed — Starry Night Portfolio

A professional React portfolio with a Starry Night inspired visual identity. Its abstract SVG sky stays in the background while the content follows a conventional portfolio layout.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Personalize the content

Edit `src/site/content.js` to update projects, experience, technologies, education, social profiles, and contact links. Replace the Smart Donation Kiosk repository placeholder and `/YOUR_RESUME_FILE.pdf` when those destinations are available. Replace the circular initials treatment in `src/site/App.jsx` with a portrait when you have one. The artwork is created from CSS and SVG; no painting image is used.
